# 🏥 BioTrack - Biomedical Waste Monitoring System[cite: 1, 7]

A smart, client-side biomedical waste monitoring system designed to track healthcare facilities, monitor container capacities, manage waste categories, and evaluate critical hazard alerts through a centralized dashboard.[cite: 1, 7]

## ✨ Key Features[cite: 7]

* 📊 **Interactive Monitoring Dashboard:** High-level operational view of waste distribution, container statuses, and active alerts across units.[cite: 1, 7]
* 🏷️ **Biomedical Segregation Tracking:** Enforces color-coded waste classification (Yellow, Red, Blue, White) aligned with biosafety guidelines.[cite: 1, 7]
* ⚠️ **Capacity & Fill-Level Monitoring:** Real-time visual threshold indicators to flag bin saturation and prevent hazardous overflows.[cite: 1, 7]
* 🚨 **Critical Alerts & Escalations:** Instant notifications for urgent pickups, critical bin levels, and facility compliance flags.[cite: 1, 7]
* 📍 **Facility Location Monitoring:** Geographic mapping and zone overview for streamlined logistics across registered healthcare nodes.[cite: 1, 7]
* ➕ **Manual Waste Entry:** Direct logging interface to record batch IDs, net weight, handler info, and collection timestamps.[cite: 1, 7]
* 📱 **Modern Responsive UI:** Fully responsive layout with clean utility styling and low-latency client-side interaction.[cite: 1, 7]

---

## ⚙️ How It Works[cite: 7, 8]

1. **Facility & Container Profiling:** Maps registered healthcare wards, departments, and their assigned waste bins.[cite: 7, 8]
2. **Category-Based Logging:** Records waste entries into strict color-coded streams (Yellow, Red, Blue, White) with timestamped weights.[cite: 7, 8]
3. **Capacity Threshold Calculation:** Evaluates live container volume against maximum safe thresholds to trigger early warning indicators.[cite: 7, 8]
4. **Alert Dispatch & Action:** Generates instant visual cues and escalation logs for bins requiring urgent clearance and safe disposal.[cite: 7, 8]
