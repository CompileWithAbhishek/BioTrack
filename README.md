# 🏥 BioTrack - Biomedical Waste Monitoring System

A smart, client-side biomedical waste monitoring system designed to track healthcare facilities, monitor container capacities, manage waste categories, and evaluate critical hazard alerts through a centralized dashboard.

## ✨ Key Features

* 📊 Interactive Monitoring Dashboard: High-level operational view of waste distribution, container statuses, and active alerts across units.
* 🏷️ Biomedical Segregation Tracking: Enforces color-coded waste classification (Yellow, Red, Blue, White) aligned with biosafety guidelines.
* ⚠️ Capacity & Fill-Level Monitoring: Real-time visual threshold indicators to flag bin saturation and prevent hazardous overflows.
* 🚨 Critical Alerts & Escalations: Instant notifications for urgent pickups, critical bin levels, and facility compliance flags.
* 📍 Facility Location Monitoring: Geographic mapping and zone overview for streamlined logistics across registered healthcare nodes.
* ➕ Manual Waste Entry: Direct logging interface to record batch IDs, net weight, handler info, and collection timestamps.
* 📱 Modern Responsive UI: Fully responsive layout with clean utility styling and low-latency client-side interaction.

---

## 🛠️ Tech Stack

- Frontend: HTML5, Tailwind CSS, Custom Utility CSS
- Engine Logic: Modern Vanilla JavaScript (ES6+)
- Deployment: GitHub Pages

---

## ⚙️ How It Works

1. Facility & Container Profiling: Maps registered healthcare wards, departments, and their assigned waste bins.
2. Category-Based Logging: Records waste entries into strict color-coded streams (Yellow, Red, Blue, White) with timestamped weights.
3. Capacity Threshold Calculation: Evaluates live container volume against maximum safe thresholds to trigger early warning indicators.
4. Alert Dispatch & Action: Generates instant visual cues and escalation logs for bins requiring urgent clearance and safe disposal.
